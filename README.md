# 🛒 Order Management API

This is a Spring Boot + JPA + PostgreSQL REST API to manage **Orders**, **Products**, and **Vendors**.  
A single order can contain multiple products, each supplied by specific vendors in specific quantities.

---

## 📦 Features

- Add / Edit / Delete Orders
- Associate Products and Vendors with Orders
- Add or remove individual Products in an existing Order
- Change the Vendor for a specific Product in an Order
- CRUD operations for Products and Vendors

---

## 🛠️ Tech Stack

- Java 17+
- Spring Boot 3
- Spring Data JPA
- PostgreSQL
- Maven
